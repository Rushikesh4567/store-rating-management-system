# store-rating-management-system

## Project Overview
Store Rating Management System is a full-stack web application that allows users to explore registered stores and submit ratings between 1 and 5 stars.

The platform provides role-based access for three types of users:
- **System Administrator:** Manages users, stores, and platform activities.
- **Normal User:** Registers, browses stores, and submits or updates ratings.
- **Store Owner:** Views customer ratings and monitors the average rating of their store.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JWT
- **Password Hashing:** bcryptjs
